# History and scope

This repository is a learning project created or reconstructed in 2026. Earlier
synthetic commit dates were corrected to 2026; they do not represent work performed
in the earlier years. Existing source snapshots and commit messages were preserved.

Where original Git timestamps survived, they informed the correction. Where they
did not, the earliest recorded commit-object write time was used. A filesystem
write time is evidence of storage activity, not an exact recovered authoring time.
Some cleaned-up snapshots use the saved creation time of their original project.

## Evidence used in this repository

- saved original Git timestamps: 1 commit(s).
- earliest recorded commit-object filesystem write time: 2 commit(s).
- existing actual 2026 Git timestamps: 1 commit(s).

These labs and fixture-based exercises do not establish production experience.
See the README and, where present, VALIDATION.md for tested behavior and limits.
